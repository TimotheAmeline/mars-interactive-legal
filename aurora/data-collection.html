Data Collection Disclosure

Aurora - Minimalist & Intentional Launcher

Aurora Launcher is designed to keep your data entirely on your device. We do not collect, store, or share any personal information.

Data We Collect: None

  • No servers
  • No analytics
  • No trackers
  • No data sharing

On-Device Only

All preferences, moods, wallpapers, and settings are stored locally. No external transmission of data occurs.

Optional Permissions

Permission Purpose Data Flow
Default Launcher To replace your home screen On-device only
Notification Access For optional visual indicators On-device only
Widget Creation To display widgets on the home screen On-device only
Lock Screen Access For double-tap-to-lock gesture On-device only
Set Wallpaper To set custom wallpapers On-device only

All these permissions are optional (except the default launcher role) and can be revoked anytime without losing app functionality.

No Third-Party SDKs or APIs

  • No Google Analytics, Firebase, or crash reporting
  • No login or social integration
  • No usage metrics

Data Export and Deletion

Aurora Launcher does not export or upload any data. To delete your local data, simply uninstall the app — all information will be removed instantly.
