Data Collection Disclosure

Scribe - Search-first Handwriting Launcher

Scribe Launcher is designed to keep your data entirely on your device. We do not collect, store, or share any personal information.

Data We Collect: None

  • No servers
  • No analytics
  • No trackers
  • No data sharing

On-Device Only

All settings, preferences, handwriting configurations, and wallpapers are stored locally. No external data transmission occurs at any time.

Optional Permissions

Permission Purpose Data Flow
Default Launcher Replace home screen On-device only

Set Wallpaper Apply wallpapers On-device only

Permissions can be revoked at any time without affecting core functionality.

No Third-Party SDKs or APIs

  • No analytics platforms
  • No advertising SDKs
  • No crash reporting services
  • No accounts or login systems

The only external dependency is ML Kit handwriting recognition, which runs entirely offline after local model download.

Data Deletion

Scribe Launcher does not export or upload data. To delete all stored information, uninstall the App — all data is removed instantly.
